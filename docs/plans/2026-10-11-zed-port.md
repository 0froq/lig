# Zed Port Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Remove lightweight project avatars and add Zed as an editor port with four downloadable themes.

**Architecture:** Keep Zed separate from the lightweight tool catalog: it maps editor UI, syntax and terminal slots from the existing ThemeIR. Generate four local JSON files and a ZIP in the current repository; serve them alongside existing downloads with a combined checksum manifest. Do not create a repository, publish an extension, or change local tool settings.

**Tech Stack:** TypeScript compiler, Nuxt/Vue, Zed v0.2.0 theme schema.

---

## Task 1: Compiler adapter

- Create `ports/zed/emit.ts` with explicit native UI/syntax bindings to shared styles/tokens, without authored palette colors.
- Generate four files and one ZIP in `ports/compile.ts`; expose identical bytes under `public/ports/zed` and include them in the public checksum manifest.
- Add adapter data contracts in `ports/zed/contracts.test.ts`, imported by the existing suite. Check native names and JSON against the official schema during implementation.

## Task 2: Downloads and installation

- Remove the lightweight avatar map/images from `app/components/palette/PaletteDownloads.vue` and restore its compact name column in `app/assets/css/palette.css`.
- Add a Zed editor card with project icon, installation notes, four theme downloads and a ZIP, highlighting the selected variant.
- Add English/Chinese copy and include Zed in `PaletteAgentSetup.vue` detection instructions. Keep user confirmation before any installation/configuration.
- Document local installation, scope and manual appearance checks in `ports/zed/README.md`; update compiler documentation and CI artifact coverage.

## Task 3: Verification and preview

- Run ESLint, `pnpm ports:typecheck`, `pnpm ports:generate`, `pnpm ports:test`, `pnpm ports:check`, `pnpm typecheck`, and `pnpm generate`.
- Validate generated JSON with the current official Zed schema and independently decode the ZIP/check checksums.
- Inspect static HTML and HTTP download responses. No UI tests or browser/computer-use checks; user manually checks icons, responsive layout, theme selection, syntax and terminal rendering.
- Commit and push the existing preview branch; wait for successful CI/Pages deployment.
