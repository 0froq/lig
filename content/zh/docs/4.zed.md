Zed 版 LiG 只是主题，不带语言服务，也还没有进 Zed 扩展商店。

## 安装扩展

固定到某个发布：

```sh
git clone --branch v0.2.2 https://github.com/0froq/zed-theme-LiG.git
```

在 Zed 里执行 `zed: install dev extension`，选择含有 `extension.toml` 的目录。然后执行 `theme selector: toggle`。

也可以从[发布页](https://github.com/0froq/zed-theme-LiG/releases)下载 `lig-zed-extension.zip`，解压后选择该目录。只装一份。

## 本地主题文件

把 `themes/` 里的 JSON 文件复制到 macOS 和 Linux 的 `~/.config/zed/themes/`，Windows 则是 `%USERPROFILE%\AppData\Roaming\Zed\themes\`。重新加载 Zed 后选择主题。

不要把扩展和本地文件以同样的名字同时安装。

## 跟随系统

```json
{
  "theme": {
    "mode": "system",
    "light": "LiG Light Paper",
    "dark": "LiG Dark Paper"
  }
}
```

先备份你原来的 `theme` 设置。
