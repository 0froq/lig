需要 Neovim 0.10 或更新版本。这个移植版是原生 Lua，不需要 Node.js，启动时也不会下载任何东西。

## 安装

用 lazy.nvim：

```lua
{
  "0froq/lig.nvim",
  lazy = false,
  priority = 1000,
  opts = { style = "dark" },
  config = function(_, opts)
    require("lig").setup(opts)
    vim.cmd.colorscheme("lig")
  end,
}
```

或者作为包安装：

```sh
git clone https://github.com/0froq/lig.nvim.git ~/.local/share/nvim/site/pack/lig/start/lig.nvim
```

然后执行 `vim.cmd.colorscheme("lig")`。

## 选择变体

不设 `style` 时，`lig` 跟随 `vim.o.background`。也可以直接指定：`lig-dark`、`lig-light`、`lig-dark-paper`、`lig-light-paper`。切换 `background` 时，会留在你选定的那一类里。

## 配置

`setup` 要在 colorscheme 之前调用。

```lua
require("lig").setup({
  style = "dark", -- dark / light / dark-paper / light-paper
  transparent = false,
  terminal_colors = true,
  styles = { comments = { italic = true } },
  plugins = { auto = true },
  on_highlights = function(groups, tokens)
    -- groups.Comment = { fg = tokens["text.subtle"], italic = true }
  end,
})
vim.cmd.colorscheme("lig")
```

`require("lig").get_tokens()` 返回当前解析后颜色的副本。用 lazy.nvim 时，`plugins = { auto = true }` 只给你已安装的插件配色。

## Lualine

```lua
require("lualine").setup({ options = { theme = "lig" } })
```

## 源码

Neovim 仓库是生成出来的。要改颜色，请改 [LiG 仓库](https://github.com/0froq/lig)，不要改 [lig.nvim](https://github.com/0froq/lig.nvim)。
