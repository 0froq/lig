title: 'VS Code'

---

需要 VS Code 1.107.0 或更新版本。扩展 id 是 `froQ.theme-lig`。

## 安装

从[发布页](https://github.com/0froq/vscode-theme-LiG/releases)下载 `.vsix`，然后：

```sh
code --install-extension theme-lig-0.2.2.vsix
```

或者使用 **Extensions: Install from VSIX…**。接着打开 **Preferences: Color Theme**，选择 LiG Light、LiG Dark、LiG Light Paper 或 LiG Dark Paper。

商店里的版本可能落后于 GitHub。如果 Marketplace 里是旧版本，请直接安装 VSIX。

## Cursor

Cursor 读取的是 Open VSX，而不是 VS Code Marketplace。在它收录这个扩展之前，请安装同一个 VSIX。没有第二个扩展 id。

## 跟随系统

```json
{
  "window.autoDetectColorScheme": true,
  "workbench.preferredLightColorTheme": "LiG Light Paper",
  "workbench.preferredDarkColorTheme": "LiG Dark Paper"
}
```

## 从 0.1 升级

0.2.0 替换了旧的配色。原来用 Soft 的地方，改选 **LiG Light Paper** 或 **LiG Dark Paper**，并更新 `workbench.colorTheme`。把 `froQ.theme-lig-preview` 禁用，避免选中旧的预览版。

## 预期

主题覆盖工作台、TextMate scope、语义 token 和终端色板。语法或语言服务对文件的分类仍可能和 Neovim 不同。你自己的 `workbench.colorCustomizations` 会覆盖主题。
