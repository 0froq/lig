七个工具，每个四个变体，颜色和编辑器是同一套，都由同一个源头生成。每个下载只管颜色：字体、快捷键和窗口行为仍由你决定。

在[移植版区域](/zh#downloads)下载某个变体，或四个变体的 ZIP。`manifest.json` 记录了源码版本、各版本号和每个文件的 SHA-256。

## Ghostty

把 `ghostty/` 复制到 `~/.config/ghostty/themes/`，然后：

```ini
theme = lig-dark
```

要跟随系统外观：

```ini
theme = light:lig-light-paper,dark:lig-dark-paper
```

主配置里明确写出的 `background`、`foreground`、`palette`、`selection-*` 或 `cursor-*` 优先于主题。

## 其他工具

fzf 使用 `fzf/lig-dark.fzfrc` 里的一行 `--color`。Zellij、tmux、Starship、bat 和 eza 在下载包里各有一个文件，放到哪里见[轻量移植说明](https://github.com/0froq/lig/blob/main/ports/lightweight/README.md)里对应的小节。

所有示例里的 `dark` 都可以换成你想要的变体。
