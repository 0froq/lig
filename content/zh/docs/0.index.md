LiG 是一个主题家族。同一套颜色走到每个工具里，换编辑器时语法的含义不变。

按你用的工具选页面。每个移植版都由同一个源头 `core/spec.json` 生成，所以不需要为某个编辑器单独调色。

| 工具 | 页面 |
| --- | --- |
| Neovim | [Neovim](/zh/docs/neovim) |
| VS Code、Cursor | [VS Code](/zh/docs/vscode) |
| Zed | [Zed](/zh/docs/zed) |
| Ghostty、fzf、Zellij、tmux、Starship、bat、eza | [终端工具](/zh/docs/terminal) |

## 四个变体

`light`、`dark`、`light-paper`、`dark-paper`。light 和 dark 用中性灰阶；paper 这一对用偏暖的低彩度底色，强调色不变。什么时候选哪个，见[变体](/zh/docs/variants)。

## 去哪里反馈

颜色、可读性、强调方式或编辑器界面有问题时，开 issue，并写明变体和移植版。在移植版仓库里直接改会在下次生成时被覆盖，改动应该提到 [LiG 仓库](https://github.com/0froq/lig)。
