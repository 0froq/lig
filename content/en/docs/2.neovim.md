Neovim 0.10 or newer. The port is native Lua. It needs no Node.js and downloads nothing at startup.

## Install

With lazy.nvim:

```lua
{
  "0froq/lig.nvim",
  lazy = false,
  priority = 1000,
  opts = { style = "dark" },
  config = function(_, opts)
    require("lig").setup(opts)
    vim.cmd.colorscheme("lig")
  end,
}
```

Or as a package:

```sh
git clone https://github.com/0froq/lig.nvim.git ~/.local/share/nvim/site/pack/lig/start/lig.nvim
```

Then run `vim.cmd.colorscheme("lig")`.

## Pick a variant

Without `style`, `lig` follows `vim.o.background`. You can also name one directly: `lig-dark`, `lig-light`, `lig-dark-paper` or `lig-light-paper`. Changing `background` stays inside the family you picked.

## Configure

Call `setup` before the colorscheme.

```lua
require("lig").setup({
  style = "dark", -- dark / light / dark-paper / light-paper
  transparent = false,
  terminal_colors = true,
  styles = { comments = { italic = true } },
  plugins = { auto = true },
  on_highlights = function(groups, tokens)
    -- groups.Comment = { fg = tokens["text.subtle"], italic = true }
  end,
})
vim.cmd.colorscheme("lig")
```

`require("lig").get_tokens()` returns a copy of the resolved colors. With lazy.nvim, `plugins = { auto = true }` themes only the plugins you have installed.

## Lualine

```lua
require("lualine").setup({ options = { theme = "lig" } })
```
