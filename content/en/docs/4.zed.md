---
title: 'Zed'
description: 'Install LiG as a Zed extension or as local theme files.'
---

LiG for Zed is a theme only. It has no language server. It is not yet in the Zed extension store.

## Install the extension

Pin a release:

```sh
git clone --branch v0.2.2 https://github.com/0froq/zed-theme-LiG.git
```

In Zed, run `zed: install dev extension` and select the directory that holds `extension.toml`. Then run `theme selector: toggle`.

You can also download `lig-zed-extension.zip` from the [releases page](https://github.com/0froq/zed-theme-LiG/releases), extract it and select that directory. Install one copy only.

## Local theme files

Copy the JSON files from `themes/` to `~/.config/zed/themes/` on macOS and Linux, or to `%USERPROFILE%\AppData\Roaming\Zed\themes\` on Windows. Reload Zed and pick a theme.

Do not install the extension and the local files under the same names.

## Follow the system

```json
{
  "theme": {
    "mode": "system",
    "light": "LiG Light Paper",
    "dark": "LiG Dark Paper"
  }
}
```

Back up your existing `theme` value first.
