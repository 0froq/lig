VS Code 1.107.0 or newer. The extension id is `froQ.theme-lig`.

## Install

Download the `.vsix` from the [releases page](https://github.com/0froq/vscode-theme-LiG/releases), then:

```sh
code --install-extension theme-lig-0.2.2.vsix
```

Or use **Extensions: Install from VSIX…**. Then open **Preferences: Color Theme** and choose one of LiG Light, LiG Dark, LiG Light Paper or LiG Dark Paper.

Store listings can lag behind GitHub. If the Marketplace has an older version, install the VSIX.

## Cursor

Cursor reads Open VSX, not the VS Code Marketplace. Until it has indexed the extension, install the same VSIX. There is no second extension id.

## Follow the system

```json
{
  "window.autoDetectColorScheme": true,
  "workbench.preferredLightColorTheme": "LiG Light Paper",
  "workbench.preferredDarkColorTheme": "LiG Dark Paper"
}
```

## Upgrading from 0.1

Version 0.2.0 replaced the old palettes. Choose **LiG Light Paper** or **LiG Dark Paper** where you had Soft, and update `workbench.colorTheme` if it still names Soft. Disable `froQ.theme-lig-preview` so the old preview is not selected.

## What to expect

The theme covers the workbench, TextMate scopes, semantic tokens and the terminal palette. A grammar or language server can still classify a file differently from Neovim. Your own `workbench.colorCustomizations` override the theme.
