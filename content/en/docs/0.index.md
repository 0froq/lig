LiG is a theme family. The same colors reach every tool, so syntax keeps its meaning when you switch editors.

Pick the page for your tool. Each port is generated from one source, `core/spec.json`, so there is nothing to tune per editor.

| Tool | Page |
| --- | --- |
| Neovim | [Neovim](/docs/neovim) |
| VS Code, Cursor | [VS Code](/docs/vscode) |
| Zed | [Zed](/docs/zed) |
| Ghostty, fzf, Zellij, tmux, Starship, bat, eza | [Terminal tools](/docs/terminal) |

## Four variants

`light`, `dark`, `light-paper` and `dark-paper`. Light and dark use a neutral gray scale. The paper pair uses a warm, low-chroma surface and the same accent colors. See [Variants](/docs/variants) for when to pick which.

## Where to ask

Open an issue for a color, readability, emphasis or editor-UI problem, and include the variant and the port. A fix made inside a port repository is overwritten the next time it is generated, so changes belong in the [LiG repository](https://github.com/0froq/lig).
