Seven tools, four variants each, all generated from the same colors as the editors. Each download is colors only: fonts, keys and window behavior stay yours.

Download one variant from the [ports section](/#downloads), or the ZIP of all four. `manifest.json` records the source ref, the versions and the SHA-256 of every file.

## Ghostty

Copy `ghostty/` into `~/.config/ghostty/themes/`, then:

```ini
theme = lig-dark
```

To follow the system appearance:

```ini
theme = light:lig-light-paper,dark:lig-dark-paper
```

An explicit `background`, `foreground`, `palette`, `selection-*` or `cursor-*` in your main config wins over the theme.

## The others

fzf takes one `--color` line from `fzf/lig-dark.fzfrc`. Zellij, tmux, Starship, bat and eza each have their own file in the download, and a short section in the [lightweight ports guide](https://github.com/0froq/lig/blob/main/ports/lightweight/README.md) shows where to put it.

Swap `dark` for the variant you want in any example.
